# 🌳 Visualizador Interativo de Árvore Binária de Busca (BST)

Este é um projeto educacional desenvolvido em **Python** com o objetivo de demonstrar de forma visual e interativa o funcionamento de uma **Árvore Binária de Busca (Binary Search Tree - BST)**. 

A cada número inserido pelo terminal, a árvore é redesenhada em tempo real utilizando a biblioteca gráfica `matplotlib`, permitindo acompanhar o posicionamento dos nós (esquerda para valores menores, direita para valores maiores).

---

## 🚀 Funcionalidades

- **Árvore Binária de Busca (BST):** Implementação clássica das regras de inserção de uma BST.
- **Visualização Gráfica Dinâmica:** A cada novo nó inserido, a interface gráfica atualiza automaticamente e destaca o valor adicionado.
- **Interface Interativa por Terminal:** Permite inserir quantos números desejar de forma contínua até decidir encerrar.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3.x**
- **Matplotlib** (para a renderização gráfica dos nós e conexões)

---

## 📦 Pré-requisitos e Instalação

Antes de executar o projeto, certifique-se de ter o Python instalado em sua máquina e a biblioteca `matplotlib`.

# 🌳 Interactive Binary Search Tree (BST) Visualizer

This is an educational project developed in **Python** designed to demonstrate the inner workings of a **Binary Search Tree (BST)** in a visual and interactive way. 

Every time a number is entered through the terminal, the tree is redrawn in real-time using the `matplotlib` library, allowing you to track the positioning of nodes (smaller values to the left, larger values to the right).

---

## 🚀 Features

- **Binary Search Tree (BST):** Classic implementation of BST insertion rules.
- **Dynamic Graphical Visualization:** With each new node inserted, the graphical interface automatically updates and highlights the newly added value.
- **Terminal-Based Interactive Interface:** Allows you to continuously input as many numbers as you like until you decide to exit.

---

## 🛠️ Technologies Used

- **Python 3.x**
- **Matplotlib** (for graphical rendering of nodes and connections)

---
